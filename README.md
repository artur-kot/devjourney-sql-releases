# DevJourney for SQL — Releases

Download page and auto-update feed for **DevJourney for SQL**, an interactive desktop app for learning SQL and PostgreSQL, with a bundled PostgreSQL server, an editor with autocompletion and an AI tutor.

**[⬇ Download the latest version](https://github.com/artur-kot/devjourney-sql-releases/releases/latest)** — Windows installer (`.exe`, NSIS) and Linux packages (`.AppImage`, `.deb`, `.rpm`).

### Requirements

- Windows 10 (1903+) with WebView2 (auto-installed), or a 64-bit Linux desktop
- Nothing else: PostgreSQL 17 ships with the app

---

The application source code is proprietary and lives in a private repository — this repository hosts release artifacts and the updater manifest (`latest.json`) only. Installed apps check here for updates automatically.
